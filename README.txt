EXPERIENCE: STORIES THAT MATTER — WEBSITE

To preview:
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. An internet connection is needed for Google Fonts and the remote stock photos used on the activity cards. The supplied Skill-Power Institute photos are included locally.

To publish:
Upload index.html, style.css, script.js, and the images/ folder to a static web host such as GitHub Pages, Netlify, or a school web server. This ZIP does not itself publish the site or create a public URL.

Interactive features:
- Navigation and responsive mobile menu
- Table of contents and section jump links
- Reading progress indicator and back-to-top button
- Activity search and category filters
- Like and bookmark states saved in the current browser only
- Share via device share sheet, or copy-link fallback where supported

Limitations:
- This is a static website. Likes/bookmarks are local to each browser and are not shared between visitors.
- There is no account system, content-management system, or database.
- The provided prompt included the introduction and section headings, but not the original full paragraphs for every section. The section copy in this build is general explanatory writing, not a verbatim recovery of missing original paragraphs. Replace those paragraphs with the exact class-written text before publishing if exact wording is required.
